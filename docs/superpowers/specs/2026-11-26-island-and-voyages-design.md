# 立体小岛 + 出海改进（2026-11-26）

> 作者："不要格子……要 3D 立体感，像一个真正的岛"；玩法审查（`reports/2026-11-26-eval-shoudengren.md`）后作者说"全都做吧"。

## A. 立体小岛（作者要求；做法 Claude 拟定，作者认可）
- 去掉六边形格子。主岛是一整块用代码生成的地形：外圈沙滩，往里起伏的草地和小山丘，几处岩石崖壁，海水在岸边自然包住。
- 扩建（`land`，0–28）让岛的轮廓整体平滑地往外长，不再一块块加格子。装饰摆在外圈坡上的固定位置。
- 灯塔、小屋、装饰等按地面高度摆放。
- 四座目的地小岛用同一套生成，形状各不相同：沉船岛是礁石滩、海鸥岩是高耸的岩柱、旧灯塔岛是长条岬角、萤火岛林木茂密的圆丘。
- 海水浪花圈沿岛的轮廓。

## B. 出海（审查建议 1–5，作者全选）
1. **航海日志**：每趟回港带一句"这趟发生的事"（按目的地和海域的模板），偶尔附小效果（多带回一点、提前回港、多一个漂流物）。到港时显示。
2. **岛民委托**：每座已发现的岛有一个委托（要某种材料若干，按当前产量定量）。送达给一次性奖励（珍品机会、一份材料、少量萤光），并让该岛友好度 +1（0–3）；友好度改变岛的样子（灯火、旗子、小屋）。委托在海图的岛卡上。
3. **满载而归**：带回珍品、首次发现或日志奖励时，回港路上船头亮灯、海鸥跟船，到港有提示。
4. **每片海的岛规则不同**：雾海——岛要灯塔再亮一级才"现形"（之前只能看到影子、不能去）；冰海——每座岛第一次要先派"破冰"航行（时长同该岛、不带货），破冰后才能登岛建房。
5. **第二艘船**：雾海起可以造第二艘船，两艘船各自出航，回港时间错开。

## 不改
