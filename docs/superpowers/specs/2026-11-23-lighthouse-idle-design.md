# 灯塔放置游戏 设计文档

- 日期：2026-11-23
- 暂定名：《守灯人》/ *Lightkeeper*（工作名，上架前需查重、确认商标）
- 状态：待作者确认

---

## 1. 意图：为什么做、为谁做

- 这是作者**人生第一个游戏**，作者没有开发经验。**主要由 Claude 编写代码和美术**，作者负责点子、试玩和反馈。
- 起因：作者想找一个**上班摸鱼时玩**的放置游戏。
- 作者最喜欢的放置游戏体验：
  1. **上线时收获一大堆**（离线收益）
  2. **一口气解锁、升级很多东西**（数字上涨 + 养成）
  3. 画面好看
- 灵感：类似 Raft 那种"捞海上漂来的东西、把家慢慢建大、去发现新地方"的玩法，但做成**挂机版本**。只借鉴玩法类型，**不照搬 Raft 的名字、角色、美术和关卡**，完全原创。
- 作者认为三种爽感都重要：**捞东西的满足感、家越建越大、发现未知**。

## 2. 目标

1. 一个**完整、可上架**的放置游戏，最终上架：苹果 App Store、谷歌 Play、Steam（PC）。
2. **开发期在浏览器里直接就能玩**，作者用手机或电脑打开链接即可试玩。
3. 每次打开游戏的一轮操作能在 **1–3 分钟**内完成："收菜 → 升级 → 关掉"。
4. 内容能玩 **2–3 个月**（每天摸鱼打开几次的节奏）。
5. 氛围：**黄昏 / 夜晚、灯塔的光、有点孤独、安静治愈**。暗色调，上班开着不扎眼。
6. **中文 + 英文**两种语言。

## 3. 非目标（第一版不做）

- 不写剧情故事。只有"瓶中信"这种一两句话的碎片文字，留一点诗意和神秘感。
- 不接入广告和内购（只预留位置，见第 9 节）。
- 不做跨平台存档同步（手机和 Steam 进度不互通）。
- 不做账号系统、不架服务器、不做联网功能。
- 不做 3D。

## 4. 反目标（做到了也算失败的情况）

- **逼氪感 / 逼人一直盯着**：放置游戏要让人放得下。离线就能有好收获，不惩罚不在线的玩家。
- **每次打开操作太繁琐**：一轮超过几分钟、点很多层菜单才能收菜，就违背了"摸鱼"这个初衷。
- **画面花哨刺眼**：亮瞎眼的特效、大量闪烁，不符合安静孤独的氛围，也不适合上班开着。
- **做不完**：范围失控导致永远上不了架。所以必须分阶段，每阶段都可玩。
- 看起来像某个现有游戏的复刻。

## 5. 约束

- 作者不写代码、不画画，所有代码和美术由 Claude 在云端环境里完成。作者只需要浏览器就能试玩。
- 上架成本（作者需知晓，属最后阶段）：
  - 苹果开发者账号 99 美元/年，打包需要一台 Mac
  - 谷歌 Play 一次性 25 美元
  - Steam 每款游戏 100 美元
- 无服务器、无运营成本。

## 6. 技术方案（已选定）

考虑过的三个方案：

| 方案 | 优点 | 缺点 |
|---|---|---|
| **1. 网页技术（TypeScript）+ 打包成各平台 App** ✅ | 浏览器直接玩，改动后作者立刻能试；一份代码出三个平台；放置游戏以按钮、数字、2D 动画为主，网页技术完全够用 | 不适合重 3D / 重特效（本游戏用不到） |
| 2. Godot 引擎 | 免费专业引擎，能导出全平台 | 作者需本地安装编辑器才能看效果，每次试玩多好几步，不适合"主要由 Claude 做" |
| 3. Unity | 业界常用 | 很重，同样需要本地操作，对小放置游戏过重 |

**作者选了方案 1。**

- 语言：TypeScript。
- 打包：手机用 Capacitor 一类工具包成 iOS / Android App；PC 用 Electron 或 Tauri 一类工具包成 Steam 可用的桌面程序。具体工具由开发者决定。
- 渲染方式（DOM / Canvas / 2D 游戏库如 Phaser 或 PixiJS）、构建工具、测试框架：**留给开发者决定**。
- 文字和代码分离：所有界面文字、物品名、瓶中信都放在语言文件里（中、英各一套），代码里不写死任何显示文字。

## 7. 游戏设计

### 7.1 核心循环（每次打开的 1–3 分钟）

1. 打开游戏 → 弹窗汇总"你不在的时候，海浪带来了：木头 ×120、瓶子 ×35……"，以及小船是否归来、岛上产出了什么。
2. 屏幕上仍有东西在漂，**点一下就捞起来**（主动操作的小满足感）。
3. 用材料升级 / 建造 / 派船出发。
4. 关掉，继续上班。

### 7.2 灯塔基地（家）

- 场景：茫茫大海上一座破旧的小灯塔和一块小平台，守塔人住在这里。
- **漂流物**：海浪把东西冲向灯塔。在线时可以点击捞取；渔网 / 钩子会**自动**捞取（离线收益主要来源）。
- **材料**：每片海域约 4 种基础材料（第一片海建议：木头、塑料瓶、绳子、金属零件），越稀有漂得越少。后续海域和岛屿加入新材料。
- **可升级项**：
  - **渔网 / 钩子**：自动捞取速度
  - **储物箱（2026-11-23 试玩后改为"收菜"）**：渔网捞到的东西先放进平台上的储物箱，画面上能看到它慢慢变满；点一下箱子全部收下。箱子满了渔网就停。在线、离线规则一致。升级 = 装得更多（起始约 2 小时的量，可升级到 12 小时）。
  - 升级要有看得见的反馈：提示条 + 渔网 / 储物箱在画面上的样子随等级变化。描述文字不写具体数字。
  - **每一级都要有看得见的变化**（作者要求）。渔网在 1/3/6/10/18/30 级换装备（手抄网 → 竹竿绳网 → 浮子拖网 → 木吊臂网袋 → 铁吊臂铁框网 → 挂满灯的捕捞架），中间每一级加细节（网里的鱼、浮子、旗、灯、海鸥、绞盘……）。储物箱 11 级每级一个样子。渔网和箱子都必须留在屏幕内。
  - 收获要有爽感：收箱子 / 捞东西时物品飞向顶部材料栏，数字滚动上涨；升级时目标处迸出光点。
- **海面**：逐帧绘制，颜色反射天空，远细近粗的浪，太阳 / 月亮 / 灯塔在水面的闪烁倒影。画面分前后层：远处的船从灯塔后面经过。
- **时间流逝**：天色 20 分钟一轮（黄昏 → 入夜 → 深夜月亮 → 黎明前 → 黄昏），跟随真实时间。海上随机事件：流星、海鸟、远处的船、跃出的鱼、鲸鱼尾巴。
- **声音**：用代码实时生成海浪声、轻柔的八音盒式背景音乐、捞取 / 收箱 / 升级音效；HUD 上有静音开关，设置会保存。
  - **平台建筑**：小屋、雨水桶、工作台等。每个有小作用，同时让画面越来越满（"家越建越大"必须能在画面上看到）。
  - **灯塔的光（主线进度）**：每修一级，光照得更远，黑暗的海面一圈圈亮起来，远处开始漂来新材料，偶尔漂来瓶中信。

### 7.3 小船远航

- 第一片海玩到约第 3–5 天，修好灯塔下的小码头，可造出小船。
- 打开**海图**，选目的地，派船出发。航程分档，例如 **15 分钟 / 1 小时 / 4 小时 / 8 小时**，越远越久、收获越好。
- 典型用法："开会前派船，开完会回来收货"。
- 小船可升级：**速度**（缩短航程）、**货舱**（带回更多）、**航程**（能去更远）。
- 海图一开始大部分是黑的。小船第一次去某方向会**发现新岛**，岛周围的海也随之亮起。

### 7.4 新岛（丰富版：可登岛建造）—— 作者明确要求丰富版

- 每片海域 3–4 个岛，第一版共约 10 个岛。
- 每个岛都**能点进去**，有自己**单独的场景画面**，可以在岛上建造。
- 为控制工作量，**所有岛用同一套建造规则**：岛上有几块空地，每块可以盖这个岛**特有**的建筑。建好后该岛自动产出，小船去时顺便带回。
- 每个岛要有自己的特色和样子。示例（具体岛的设计留给开发者，但要达到这个"各有特色"的程度）：
  - **沉船礁**：拆解台，产出大量金属零件
  - **海鸟岩**：一只海鸟跟你回家，帮你叼东西（自动捞取加速）
  - **废弃灯塔**：找到图纸，解锁新建筑
  - **萤火小岛**：产出只有这里才有的发光材料，修灯塔高级阶段必需
- 有的岛给一次性奖励，有的岛可以反复派船去采特定材料。

### 7.5 长线：海域轮回（让游戏撑 2–3 个月）

- 灯塔完全修好、照亮整片海域后，守塔人"把光传下去"，**前往更远海域的另一座灯塔**，从头开始。
- 带走一种永久货币（暂名"星光"），用于永久加成，所以下一轮更快、能走得更远。
- **旧海域保留（作者选定）**：每片海是一个独立的"家"。去新海域时，旧灯塔、平台建筑、岛和岛上建筑**全部保留**，并**继续慢慢产出**（速率可低于当前海域，具体由开发者定）。海图上可以随时切换回去查看、收取。新海域从头建起，叠加星光加成。"家越来越大"在长线上变成"守护的海越来越多"。
- 跨海域永久保留：星光、小船（及其升级）、瓶中信、图鉴、成就。
- 存档结构因此分为：全局数据（星光、小船、收集、成就）+ 每片海域各自的数据（灯塔、建筑、岛、材料）。各海域材料是否互通由开发者决定。
- 第一版 **3 片海域**，每片换一套配色、新材料和新岛，例如：
  1. 黄昏的海
  2. 有雾的夜海
  3. 极光下的冰海
- 3 片海走完之后的玩法（例如可重复轮回、无尽模式）：**留给开发者提议**，需保证游戏不会在 2 个月内"没事可做"。

### 7.6 收集与长期目标

- **瓶中信**：收集册，每封一两句话，中英两版都要写得有文学味。由 Claude 撰写，作者审阅。
- **稀有漂流物图鉴**、**成就**。

### 7.7 节奏

- 前几天升级快、很爽；之后每一级要攒更久。
- 整体（3 片海 + 岛 + 收集）调到约 **2–3 个月**。具体数值曲线由开发者设计，并需要提供一种开发期加速 / 调试手段，方便检验长期节奏。

## 8. 美术与声音

- 第一版**全部由 Claude 用代码绘制**：简约统一的扁平 / 矢量插画风，圆角、柔和配色、暗色调为主，灯塔的光是视觉焦点。
- 小动画：海浪起伏、漂流物摇晃、灯塔光扫过、捞起时的小反馈。动画要安静，不刺眼。
- 以后若决定认真上架，可能请画师或用 AI 升级关键画面。**美术实现要便于以后整体替换。**
- 声音：海浪声等安静的环境音（具体做法留给开发者；需有静音开关，上班场景很重要）。

## 9. 商业化（第一版不接入，只预留）

- 手机：免费 + **"看广告领奖励"**（例如"离线收获翻倍"）+ **一次性付费永久去广告**。
- Steam：**低价买断**（约 2–5 美元），无广告。
- 第一版：不接入任何广告 SDK 和付费。"离线收获翻倍"等按钮先**免费可用**，代码结构上留好以后接广告的位置。

## 10. 存档

- 存档保存在设备本地，自动保存。
- 上架时接入各平台自带云存档（Steam Cloud、iCloud、Google Play 存档），实现同平台换设备不丢进度。
- **不做跨平台同步**。但存档要设计成一个独立、带版本号的数据包，便于以后加跨平台同步和做存档升级。
- 离线收益依赖设备时间，防改时间作弊的处理方式留给开发者决定（单机游戏，宽松处理即可）。

## 11. 开发方式：分阶段，每阶段可玩

范围较大，必须分阶段，每完成一阶段作者都能在浏览器里玩到，全部完成并调好后再上架。

**试玩方式（作者选定）**：用 GitHub Pages 托管，仓库 `tony072319/games` 设为公开。每次推送后自动构建部署，作者用手机或电脑打开同一个网址即可试玩。第一阶段就要把这条自动部署流程搭好。

阶段划分建议（最终由实施计划确定）：

1. 灯塔基地：漂流物、点击捞取、自动捞取、材料、升级、离线收益、存档
2. 平台建筑 + 灯塔之光主线 + 瓶中信
3. 小船 + 海图 + 发现新岛
4. 登岛场景 + 岛屿建造
5. 海域轮回 + 3 片海域 + 星光永久加成
6. 收集册、成就、中英文全量文字、声音
7. 数值调优（2–3 个月节奏）、手机 / PC 适配
8. 打包上架准备（各平台打包、云存档、商业化接入）

## 14. 第一片海：灯塔之光 + 小船 + 发现新岛（2026-11-23 作者确认）

作者决定先做这部分（原第 2 阶段的平台建筑、瓶中信延后）。进度由**灯塔之光**决定。

**灯塔之光**
- 升级面板第三项"灯塔"，第一片海最高 10 级；每一级灯塔外观都有可见变化（塔身修复、刷漆、铜饰；灯更亮、光束更长）。
- 3 级：修好码头，可以造小船。
- 灯塔光照范围决定海图上能去多远（每级亮一圈）。
- 7 级起需要新材料"萤光"，只能由小船从萤火小岛带回。
- 10 级：这片海完成（第 4 步做"前往下一片海"）。

**小船**
- 码头修好后造船（一次性材料）。平台旁停着小船。
- "海图"：选目的地派船，航程 15 分钟 / 1 小时 / 4 小时 / 8 小时。出航时码头空着，海图上显示航行中的小船和剩余时间。离线照常航行。
- 回来后船上堆着货，点小船卸货（物品飞进材料栏）。
- 小船升级：船速（航行变短）、货舱（带回更多）。

**第一片海的 4 个岛**（第一次到达 = 发现，一次性奖励；之后可反复去采集）
- 沉船礁（15 分钟）：大量金属零件。
- 海鸟岩（1 小时）：海鸟跟回家，渔网永久变快。
