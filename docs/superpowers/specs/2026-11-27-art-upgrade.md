# 美术全面提升（2026-11-27）

> 作者："我对你的主要任务是做美术、动画、图片什么的，我需要你全面提升我的美术。你可以去网上找任何公开的资源，你也可以自己创造。"
> 作者没有指定做法，所以下面的做法都是 Claude 拟定，作者可以改。风格标准不变：样张 G（柔和、生动、温馨、可爱；黄昏、孤独、温暖的灯）。

## 现在的画面哪里不好（截图对比样张 G 得出）

1. **雾海坏了**：整座岛糊成一片粉色剪影，什么都看不清。
2. **灯光束**：夜里是一块硬边的浅色色块，不像光。
3. **天空**：白天发白、地平线一条灰带；云是灰褐色的低模团；没有太阳和月亮。
4. **海**：一片平的青色，照亮范围的边缘是一条硬线；样张 G 里那种柔和的白色浪纹没有了。
5. **岛**：像三层蛋糕。草地是一块平的绿色，崖壁是一圈褐色色带，路是一条细线，没有草丛、石头、花。
6. **模型**：几家素材混在一起，大小不统一（红色吊车比房子还大），颜色抢眼。
7. **动的东西少**：升级只有"弹一下"；船没有尾迹；旗子、风车、树都不动。
8. **图片**：36 件珍品是占位用的简笔图；升级卡片的小图很小很暗；没有网页图标和分享图。

## 做法（一种，不换风格）

继续用 three.js 和现有模型体系，在样张 G 的方向上把每一层补到位。不换成写实，不换成像素，不重做玩法和界面结构。
别的路为什么不走：换一整套新风格要作者重新选样张，而且以前选过的 G 还没有做到位；全部换成新素材包风险大、慢，先把"光、水、天、地"做好，收益最大（之前的资源调研也是这个结论）。

## 顺序

1. **天、海、光、雾**：手绘感渐变天空 + 太阳/月亮 + 柔软的云；有深浅、有浪纹、有波光的卡通海；柔和的体积光束和海面光斑；雾海改成"岛看得清、远处和海面有雾"；极光更明显；整体调色（暗角、暖色）。
2. **岛的地面**：草地有深浅变化，崖壁有岩层，沙滩有湿边，路是真的路；散布草丛、野花、石头；树随风摆。
3. **模型**：统一大小和颜色；换掉不协调的（吊车、方盒子船等），需要时从公开的 CC0 素材里补；更新素材致谢。
4. **动画和反馈**：升级时的光点和光圈、捞东西的水花、船的尾迹、炊烟、旗子、风车、海鸥扇翅膀。
5. **图片**：36 件珍品重画，升级卡片小图重画，网页图标、分享图、加载画面。材料图标是作者自己的图，不动。

## 不变的

- 规则、数值、存档、界面结构、文字。`src/core` 不动。
- 手机上的流畅度：不加昂贵的后处理（不做屏幕空间环境光遮蔽、不做反射）；新效果都在着色器里做，或者用很少的面。
- "减少动画"模式下新动画同样关闭。
- 所有测试照常通过；素材只用授权写明可商用的，并写进致谢。

## 怎么算做好

每一步都截图对比（手机竖屏和宽屏、白天和夜晚、三片海），截图放在 `reports/art/`。

## 做的过程中作者的反馈（2026-11-27）

作者："我希望这个岛更真实一点，现在有点假，这样一层一层感觉不是很真实。"

改法：主岛不再是三层台地加石墙，而是一座连绵的小山。
- 从沙滩到岸边平地、缓坡上到镇子所在的山肩、再一段坡到灯塔所在的山顶，一路都是坡，没有环形石墙。
- 山的高低绕岛一圈都不一样（山肩一边高一边低，有两三处小丘和一处洼地），海岸线有长边、岬角和小湾。
- 只有真正陡的地方才露出岩石；岩层是倾斜、弯曲的，不再是一圈圈横条。岛背面保留一段海崖，崖下有礁石和海蚀柱。
- 房子建在坡上时往地里"挖"一点，不会有一角悬空。树也长到坡上。
- 路：海边一条滨海路，镇上一条街，码头到镇子、镇子到灯塔各有一条上坡路。

## 实际做了什么

| 部分 | 内容 | 主要文件 |
|---|---|---|
| 天 | 落日（半落）、月亮、圆的星星、从下方被照亮的云、极光、流星夜 | `src/world/sky3d.ts` |
| 海 | 深浅渐变、柔和浪纹、日月下的波光、灯光束照到海面的光斑、清晰的海平线 | `src/world/water.ts` |
| 光和空气 | 双光束 + 灯罩闪光、远处的云、雾海的薄雾（岛看得清）、最后一道调色（暗角、颗粒） | `src/world/atmosphere.ts` |
| 天气 | 风暴（雨、暗天、大浪、云后闪电）、流星夜、鲸群 | `src/world/scene.ts`、`effects.ts` |
| 地面 | 草地深浅和小花、沙滩湿边、倾斜岩层、土路 | `src/world/ground.ts`、`terrain.ts` |
| 植物 | 草丛、野花、灌木、石子、树（随风摆；冰海有积雪，雾海偏灰） | `src/world/greenery.ts` |
| 模型 | 小镇统一用 KayKit 中世纪六边形包（CC0）：黄昏海蓝顶、雾海绿顶、冰海红顶；船换成 Kenney 木船；守灯人小屋黄顶 | `src/world/town.ts`、`looks.ts`、`assets.ts` |
| 动画 | 修好时的光圈和光点、新东西落地的弹出和尘土、船尾迹、捞起的水花、风车和水车转动 | `src/world/effects.ts`、`scene.ts` |
| 图片 | 卡片小图改成真模型的照片（75 张）、36 件珍品重画、海图和 4 座岛的小图重画、网页图标、分享图、加载画面 | `src/ui/art/*`、`public/thumbs`、`public/favicon.svg`、`public/share.jpg` |

工具：
- `tools/world-check.html`：看任意时刻和角度的世界（`?sun=&moon=&sea=&event=&tilt=&zoom=&turn=`）。
- `tools/model-sheet.html`：模型对照表。`tools/curio-sheet.html`：珍品对照表。
- `tools/make-thumbs.mjs`：重新拍卡片小图（改了 `looks.ts` 之后要跑一次；`tests/ui/thumbs.test.ts` 会提醒）。

对比图：`reports/art/before/`、`reports/art/after/`。

## 没做和要知道的

- **流畅度**：没有显卡的软件渲染下，满级小镇每秒画的帧数比改之前少约 20%（开局时少约 14%）。真机上没测过。如果手机上卡，先减的是：树和草的数量（`greenery.ts`）、阴影贴图大小、泛光。
- 旧的 2D 手绘图（`src/ui/art/scene.ts`、`net.ts`、`chest.ts`、`tower.ts`、`boat.ts` 里的船和码头）游戏里已经不用了，文件和它们的测试还在，可以删。
- 材料图标是作者自己的图，没动。
- 萤火小岛上的茅屋、棕榈树等还是原来那套较简单的模型。
- 人物只有走路和站立的动画；海鸥不会扇翅膀（模型没有翅膀关节）。
