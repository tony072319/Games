# 点岛上的东西来操作（去掉底部按钮）+ 数值复查（2026-11-26）

> 作者："继续做点岛的建设，减少下面的按钮，最好交互都可以通过触摸岛上的东西来触发，然后再看一下数值有没有需要改的。"

## 设计（Claude 拟定）
去掉底部工具栏（海图、图鉴、装饰、海域、传光）。每个功能都挂到岛上的一样东西上：

| 点什么 | 打开 |
|---|---|
| 灯塔 | 灯塔升级卡片；修满且能传光时，直接弹出"传光"确认 |
| 渔网 / 储物箱 | 各自的升级卡片（现在就是） |
| 守塔人小屋 | 图鉴（有新收藏时小屋上方闪光） |
| 码头、小船（没货时） | 海图（现在就是）；海图顶部加"切换海域"（去过两片海以后） |
| 镇上的房子、装饰、岛的地面 | 建设面板（扩建 + 装饰）；有买得起的东西时镇子上方闪光 |
| 漂流物 / 夜里的船 / 小岛 | 和现在一样 |

- 每个可点的东西都有看不见的按钮（键盘、读屏可用），"下一步"目标条点了会把对应的东西闪一下。
- 新玩家能找到：灯塔、守塔人小屋、镇子在能买/有新东西时会闪光；"下一步"会提示去点哪里。
- 擦亮灯的小按钮仍在卡片上方（不在底部）。

## 数值复查
用模拟器把三类玩家（普通、勤快、新手首局）跑一遍，看最近加的东西（首局优惠、两艘船、委托、航海日志、引航、小镇）有没有让某处失衡；需要改的就改，并把结论告诉作者。
