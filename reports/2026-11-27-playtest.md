# 新手试玩记录（2026-11-27）

用浏览器机器人（`tools/playtest-bot.mjs`）以新玩家身份按真实时间玩：每 1.5 秒点漂流物、收储物箱，买得起就买，有船就出海。手机竖屏，正式版（不是测试版）。

## 时间线（第二局，16 分钟）

| 时间 | 发生了什么 |
|---|---|
| 0:05 | 提示"点一下海上漂过来的东西" |
| 0:15 | 提示"点储物箱" |
| 0:22 | 提示"修整渔网" |
| 1:34 | 提示"把灯塔修到 3 级" |
| 7:01 | 灯塔 2 级 |
| 8:44 | 灯塔 3 级，提示"打开海图，造一艘小船" |
| 9:34 | 造船并第一次出海（3 分钟试航） |
| 9:35 | 提示"夜里有船经过，点一下引路"（修好后才出现，只出现一次） |
| 12:15 | 船回港，发现"沉船礁"，第二趟出发（13 分钟） |
| 16:00 | 灯塔 3 级、渔网 15 级、储物箱 7 级；手上：木头 335、塑料瓶 4223、绳子 1162、金属 1641 |

## 发现

1. **已修**：夜里"给船引路"的提示原来会在第 1 分钟就出现，并且每来一艘船都会盖住"修灯塔造船"这个主线提示。现在要等造好船以后才出现，而且每次打开只提示第一艘船。
2. **待定（数值）**：木头不够用，其他材料堆着用不掉。第 16 分钟手上 7000 多个塑料瓶/绳子/金属，却什么都买不了，因为渔网只花木头，灯塔 4 级要 1210 木头。提示条只能写"再等 3 分钟"。
3. 首局节奏达标：机器人不按提示走，见什么买什么（先把木头花在渔网上），仍然在第 9.6 分钟出海；按提示走的玩家会更早。
